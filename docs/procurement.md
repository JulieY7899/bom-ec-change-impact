# B19 采购承诺与到货核查

V1.2-B19（0.3.0） 按用户确认的 B19-DRAFT01 实现。采购证据用于工程、采购和计划共同确认；累计净到货不等于可用库存，剩余承诺不自动加入在途、Open PO 或原备料公式。`approved_action` 始终为 `null`。B22 工程版本与订单引用仍未实现。

## 导入与复现

数据准备页提供“采购与到货示例（虚构数据）”，也可打开 [XLSX 示例](../outputs/b19-import-template/B19采购与到货导入示例.xlsx)。含填写说明、虚构 BOM、采购行和两笔收货。实际使用须替换全部示例行，并与本次 BOM/订单一起选择、整批导入。填写说明不是数据表，当前导入器会提示该工作表未识别；三张数据表仍正常识别。本示例不包含企业真实数据。

示例核查：替换 `PART-OLD` → `PART-NEW`，生效日 `2026-12-01`，核查标签 `BOM-000001`，工厂 `PLANT-T`，库位 `STORE-T`。结果为采购总量50、累计净到货20、剩余承诺30、取消量0；12和8两笔收货净额为20；供需情景未填，原备料建议继续显示待补供应数据。

一批导入先暂存，全部成功后备份并发布。非法采购行、冲突重复、缺必填业务键、坏日期等使整批失败，旧快照与旧报告保留。新采购表参加快照清理、取消、失败重试及成功前备份。

## 两类标准明细

首行使用下列中文列名；纯空行忽略。编号按文本填写以保留 `00010` 等前导零，禁止科学计数法。日期使用 `YYYY-MM-DD` 文本或 Excel 日期；读取后均校验有效日历日期。未知数量留空，真实零填0。

| 列 | 采购行快照 | 到货流水 |
| --- | --- | --- |
| 采购数据类型 | `PURCHASE_LINE` | `RECEIPT` |
| 采购单号、采购行号、物料、工厂 | 必填 | 必填 |
| 库位 | 可空，范围待确认，不参与完整合计 | 可空，无法完成精确核对 |
| 计量单位、数据截至日 | 可空，阻止完整数量汇总 | 必填 |
| 采购总量、累计净到货量、剩余未到货承诺、取消/关闭未交数量 | Q/R/O/C；有限非负数，可空 | 不使用 |
| 采购状态 | OPEN / CLOSED / CANCELLED / UNKNOWN | 不使用 |
| 可取消性 | YES / NO / UNKNOWN | 不使用 |
| 质量状态 | RELEASED / HOLD / UNKNOWN | 不使用 |
| 预计到货日 | 可空，不代表届时可投料 | 不使用 |
| 到货凭证号、凭证年度、凭证行号 | 不使用 | 必填，构成流水唯一键 |
| 业务日期、类型、数量 | 不使用 | 日期必填；类型 RECEIPT / RETURN / REVERSAL；数量须为有限正数 |
| 历史完整性 | 不使用 | COMPLETE / PARTIAL / UNKNOWN；仅输入方确认覆盖全部历史才能填 COMPLETE |
| 被冲销凭证号、被冲销凭证年度、被冲销凭证行号 | 不使用 | 冲销时提供；不支持的引用保留证据并标需复核 |

采购行业务键为采购单号＋采购行号＋工厂。相同键相同内容只计一次、保留所有来源行；内容或截至日冲突拒绝整批。流水同样去重与拒绝冲突。未知枚举保留为 UNKNOWN，不执行默认批准。

原 B19 的列名“物料、工厂、库位、采购总量、已到货量、剩余采购承诺、可取消”继续支持。其50/20/30作为范围汇总展示；不虚构采购单、单位、截至日或到货流水。与同范围明细同时存在时标记可能重叠，禁止相加。

## 已确认规则

- 替换核查旧料及新料；新增只核查新料，删除/用量/生效性只核查被改物料。不扩入无关上下层采购。
- 物料、工厂、库位精确匹配。查询范围或记录库位缺失时分范围列候选，禁止跨范围完整合计。
- 未知量保持 `null`，不补零，不用 Q−R 补未知 O。Q/R/O/C 都已知时按绝对容差 `1e-6` 核对 Q=R+O+C；矛盾保留原数并阻止可信合计。
- 收货正向、退货负向，全额冲销取原收货/退货的反方向。部分冲销、冲销的冲销、重复冲销或缺目标保留证据并阻止完整流水净额。
- 仅业务日期不晚于采购行截至日的流水参与净额；当天包含，未来流水单列排除。不同截至日或历史不完整时，只展示已提供净额和覆盖待确认，不覆盖 R。
- COMPLETE 且无效数据已排除时比较流水净额与 R；冲突同时展示两数并标需复核，禁止重复累计。
- 按物料、工厂、库位、单位、截至日分组；逐字段汇总。任何对应量未知或不可信时完整合计为 `null`；已知部分另列且不充当总量。
- 关闭/取消不抹掉历史到货，O非零时标状态冲突。可取消性 YES 与质量 RELEASED 都只是源记录，仍需共同确认。
- 预计到货晚于生效日提示晚到；同日只表示日期相符，不推定可投料。缺质量、日期、单位或明细的缺口保留。
- API、计划页、网页报告和 Markdown 使用同一采购呈现合同。一个采购行多项 ECN 命中只计一次，保留所有变更关联与来源行。
- 名称、描述、联系人、自由备注与原始文件路径不进入采购模型、API或报告。只保留白名单业务字段和来源编号/工作表序号/行号。

自动验证覆盖 P19-01..28，以及截至日不一致、采购快照失败/成功备份、可下载示例导入以及 Excel 原生日期单元格四项回归。原25例预期另行冻结，不由新增测试重写。自动测试运行结果见 [GitHub Actions](https://github.com/JulieY7899/bom-ec-change-impact/actions/workflows/verify.yml)。

# 业务核查工作流

打开首页进入「业务核查工作流」。可以先用对话整理核查参数，再按预检列出的需要准备 Excel 导出。普通模式接受展开 BOM，按工程版本核查需要明确定义的 EBOM、BOM 行和订单引用。可选采购及到货资料沿用已有模板。

## 从问题到结果

| 步骤 | 输入 | 可检查的输出 |
| --- | --- | --- |
| 参数确认 | 业务问题、角色、核查模式、变更类型、物料或 BOM 行、拟生效日 | 可编辑参数。识别不到的范围由业务人员填写 |
| 数据预检 | 已确认参数和当前导入快照 | 来源和行数、缺字段、版本引用或行适用性待核。必填项不足时无法运行 |
| 01 数据准备 | 在预检结果中点「带入 01 数据准备」 | 沿用已填参数，列出要核对的资料和当前快照覆盖情况。可返回核查表继续操作 |
| 规则核查 | 预检后的结构化参数 | BOM 路径、销售行、生产工单、采购承诺或版本引用，以及原始来源 |
| 角色核查与报告 | 规则结果 | 角色相关事实及待复核事项。网页和下载使用同一份运行记录 |

预检绑定当前导入快照。成功导入后，页面用同一组参数自动重新预检。核查参数用于筛选和核对导出范围，Excel 由使用者选择导入。原始业务问句用于参数识别，运行记录保存确认后的字段、业务关注项和证据。

重新打开页面可查看当前快照中最近一次工作流结果。替换导入快照后，旧快照结果随本机快照备份保留。

可用虚拟演示快照试试「我是采购，COMP-001 无法及时采购，替代采购件为 COMP-998，有什么影响？」。助手识别采购视角、替换类型、原组件和新组件，只追问拟生效日期。补充「2026/12/1」后可以一键填入核查表。已有值的改动会在填入前显示。切换成品、工厂或版本后，需要重新确认目标 BOM 行。

也可以打开核查表直接编辑业务参数。启用账号库时，核查角色以右上角登录会话为准。对话消息保留在当前页面，运行记录使用已填入的结构化参数和识别出的业务关注项。选择研发查看结构，选择销售查看订单行和需求日，选择制造查看工单，选择工程查看工程路径与版本引用。

工程模式示例可导入「工程版本与订单引用示例」，再输入「从销售角度，成品 FG-T1，工厂 PLANT-T，工程版本 ENG-V2，BOM 行 V2-L2，2026-12-01 把 PART-OLD 换成 PART-NEW，哪些订单行要复核？」。采购工厂和采购库位用作采购核查范围，工程版本工厂用作版本定位范围。

## 账号和角色

1. 点击网页右上角「账号登录」，输入管理员分配的账号和口令。登录后同一位置显示账号和当前角色。
2. 多角色账号可展开菜单，在「当前角色」选择一个已授权的角色。单角色账号直接显示其角色。核查表中的角色随登录会话更新。
3. 切换后保留已填参数，按新角色重新预检。已经生成的报告仍绑定原核查记录和原角色。换用另一账号时，从同一菜单退出后重新登录。

| 操作 | 服务端条件 |
| --- | --- |
| 预检及运行 | 启用账号库时须登录，服务端使用会话当前角色。在同一账号切走再切回后，旧预检也须重做。 |
| 工程知识库的目录、材料预览、入库和检索 | 工程部门账号，当前角色为工程，且从已完成的工程角色核查进入。角色切换会立即清空页面上的摘录及预览。 |
| 工作流及 04 报告 | 使用各自的核查记录。报告正文、下载和原报告编号均独立于知识库。 |

采购部门账号即使获准使用工程核查视角，知识库入口和接口也只有工程部门账号在工程角色下可用。切到采购后，页面立即清空旧摘录和预览。切回工程后可重新检索。

### 本机配置示例

本机管理员在受操作系统保护的独立目录维护账号库。服务以只读方式打开它。授权顺序的首项是默认角色。以下命令在用户目录下创建独立的试用目录，配置一个可切换的工程账号和一个采购账号。

```sh
bom_trial_dir="$(mktemp -d "$HOME/bom-account-demo.XXXXXX")"
python3 scripts/set_account.py --accounts "$bom_trial_dir/accounts.sqlite3" eng01 engineering --roles engineering procurement
python3 scripts/set_account.py --accounts "$bom_trial_dir/accounts.sqlite3" buy01 procurement
python3 app.py --database "$bom_trial_dir/demo.sqlite3" --accounts "$bom_trial_dir/accounts.sqlite3"
```

管理员按提示输入口令。可在「01 数据准备」给试用数据库载入虚拟演示数据。重设口令或变更部门、角色时，此前的登录会话随即失效。旧账号库可直接读取，工程、采购沿用各自的单角色，`other` 默认为研发。启用多角色时由管理员在库的副本上更新账号即可。未指定账号库时，普通本机演示保留核查表角色选择，工程知识库关闭。登录和退出会刷新页面。登录状态限当前标签页，会话最长八小时，重启服务后需重新登录。

## 03 影响核查中的工程辅助分析

1. 从右上角登录工程部门账号，确认当前角色为工程并完成一次核查。在「03 影响核查」展开「工程辅助分析 · 知识库」。
2. 选择脱敏的 PPT、PPTX、UTF-8 Markdown 或 TXT，点击「提取文本并预览」。演示文稿按原页展示，Markdown 和 TXT 按空行分段。旧版 PPT 由本机 LibreOffice 临时转换。逐项编辑摘录、勾选，选择存放分区，按需填入脱敏标题，确认后点「加入知识库」。
3. 在「已入库材料」查看各分区的材料标题、文档编号和片段数。可选分区为工程规范、变更案例、验证与判定、待归类。同一文件再次提交时，新的分区和勾选内容整体替换旧索引。文件内容变化会生成新的文档编号。
4. 选择「检索分区」，在「工程问题」输入料号、规范编号或关键术语，再点「检索工程知识」。选择「全部分区」可扩大范围。留空时按本次变更类型、核查关注点和已填料号、工程版本、BOM 行号检索。启用 Qdrant Local 后可用中文自然语言检索。在「已入库材料」可确认当前检索方式。每次最多显示三条审核过的原文片段，可按文档编号、原页或原段、片段号回查。知识摘录仅在工程辅助分析面板内显示。工作流和 04 报告继续使用业务规则的结果。

入口缺失时，请核对启动时是否指定账号库、登录账号是否属于工程部门、当前角色是否为工程，以及打开的结果是否由工程角色完成。

### 本机存储与检索

| 项目 | 实现 |
|---|---|
| 存放位置 | 与业务库同目录的独立文件 `<业务数据库文件名>.engineering-kb.sqlite3`，按工程材料分区管理。原文件和本机文件名均不入库，便于按需备份。请另外保管原材料。 |
| 审核和切块 | PPT 和 PPTX 最多 12 MB、80 页，每页预览最多 1200 字，超过时页面提示截断，图片和备注不提取。TXT/MD 最大 256 KB，最多 80 段，每段最多 1200 字。只将勾选的内容切成最多 300 字的块，优先在句末或换行处分割，长页相邻块保留 40 字上下文。 |
| 向量和搜索 | Qdrant Local 把已审核的片段转为 512 维向量，索引存放在同目录的 `<业务数据库文件名>.qdrant/`，可由审核库重建。按分区搜索并优先匹配完整料号。未启用本机模型时可使用 SQLite 词项检索。 |
| 容量和兼容 | 每个库上限 30 份材料。首次工程访问会将旧业务库中已审核的 PPT 摘录复制到「待归类」，保留原编号、页码和旧记录。后续更新保存在独立知识库。 |
| 备份和权限 | 独立备份知识库文件，复制时先停止服务。业务快照回滚不会回滚独立知识库。存放账号库、业务库、知识库及备份的目录均应由操作系统限制直接文件访问。 |

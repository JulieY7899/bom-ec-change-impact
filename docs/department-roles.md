# BOM 影响核查的部门账号与验收标准

各岗位用独立账号对同一拟议变更开展核查。表中的「确认」由岗位人员在正式流程中完成。网页按本机数据给出匹配证据和待补资料。

| 岗位 | 角色代码 | 核查输出 | 岗位确认 |
|---|---|---|---|
| 工程 | `engineering` | BOM 路径、版本引用、生效范围，工程知识库 | 新旧组件差异、产品及工厂适用性、临时替代条件 |
| 研发 | `rd` | 组件结构、设计验证待办 | 替代、互换、验证及配置限制 |
| 采购 | `procurement` | 采购行、剩余承诺、到货、退货和冲销 | 供应商投产或发货、可改可撤数量、继续收货及承诺日期 |
| 计划物控 | `planning` | 按物料、工厂和库位查看备料情景原值、关联订单需求与采购证据覆盖 | 按采购订单行核对在途与未交重叠，再判断旧料剩余、新料缺口、齐套日期和切换方式 |
| 仓储物流 | `warehouse` | 采购收货凭证覆盖及实物库存资料缺口 | WMS 库位、批次、在途、待检与隔离状态，确认何时可转可用库存 |
| 制造 | `manufacturing` | 工单关联、执行状态和版本适用性 | 实际领料、工序及在制状态，逐单确认改料、继续制造、隔离、返工或暂停 |
| 质量 | `quality` | 已有的新组件主数据和寻源检查结果，质量证据缺口 | 新料验证、批次与在制风险、复验、返工及放行 |
| 销售 | `sales` | 销售订单行、需求日期和明确的版本引用 | 配置替代、交期调整、交付承诺及沟通 |
| 售后服务 | `service` | BOM 成品关联线索和已交付设备资料缺口 | 按已交付设备和维修备件版本确认兼容性、旧件保留及维修替代 |

## 采购与计划物控

两个角色共享采购与到货证据的匹配结果。采购核对订单行的供应商责任与承诺，计划物控核对可用库存、交付时序和切换条件。计划岗位分别展示库存、在途、未交采购和需求情景输入，不把采购剩余承诺或收货凭证自动累加成可用量。缺少采购行级重叠核对时，岗位结论标记为待核。共同报告中的备料情景计算按其原有假设保留。

## 权限规则

- 每个试用账号仅授予其本岗位角色。管理员可按实际职责明确授予多个角色，服务端每次使用当前会话的一项角色。已有账号库及历史报告沿用原角色和授权。
- 工程知识库要求工程部门、当前工程角色及工程角色运行记录同时成立。研发、采购、计划和其他岗位的知识库访问均被拒绝。
- 所有已授权的部门账号都可在「04 核查报告」查看并下载同一次 BOM 变更对各部门的影响，包括其他部门发起的核查。网页与下载版共用同一份业务影响结果，展示当前范围内的证据和待核事项。仓储、质量及售后等缺少业务凭证时，相关事项列为待补。
- 「角色核查结果」提供当前岗位的专项输出。工作流报告保留发起岗位的专项输出和完整规则证据。工程人员选用的知识片段只补充现有规则结果，生成待复核的工程辅助推论。只有工程部门账号使用工程角色时，才能查看推论和下载含推论的工程报告。
- 账号和运行数据库由本机管理员保管。试用口令在本机生成，账号库、材料和报告独立于源码。

## 发布验收标准

| 编号 | 输入与操作 | 预期 |
|---|---|---|
| R01 | 分别登录九个单岗位账号 | 右上角显示账号和准确角色。尝试切换至未授权角色或提交其他角色的预检，均返回 403 |
| R02 | 所有岗位对同一个替换案例完成预检、核查并下载 | 各岗位看到自己的证据或待补项、人工确认事项。工作流报告沿用实际核查角色和运行编号 |
| R03 | 同一采购行的采购和计划物控核查 | 采购保留剩余承诺与收货结果。计划列出输入及行级重叠待核，不将采购剩余承诺和在途相加，不把未知补零 |
| R04 | 仓储、质量、售后缺少对应的实物、质量或已交付设备凭证 | 分别提示需要补齐的资料；收货不直接记为可用库存，主数据检查不直接给放行结论，BOM 关联不直接给已交付设备兼容结论 |
| R05 | 使用工程账号查工程核查记录，再换到其他岗位账号访问同一记录 | 工程账号可访问知识库，其他八个账号的目录、预览、入库与检索均返回 403。工作流与常规下载无知识摘录 |
| R06 | 保留既有多角色工程账号、旧账号与旧核查记录 | 原授权保持可用，切到非工程后旧预检、知识入口和摘录失效，原报告仍可打开 |
| R07 | 对话写明计划物控、仓储物流、质量或售后 | 识别正确视角；已认证会话的角色以右上角为准 |
| R08 | 检查独立目录、本机全量回归与 GitHub Actions | 既有业务标准继续通过，发布内容只含源码、测试及说明，原项目及数据通过保护复验 |
| R09 | 采购及其他岗位分别打开并下载工程账号生成的通用报告 | 每个账号看到同一编号和跨部门业务结果，计划、制造等可用证据及各部门待核事项共用，通用报告无知识库片段和工程辅助推论 |
| R10 | 工程账号在「03」选用已审核片段，再打开「04」并下载含工程推论的报告。其他岗位尝试打开同一附件 | 两个页面及工程报告显示同一份规则依据、片段及待复核建议。通用报告保持原结果。其他岗位无法查看或下载工程附件 |

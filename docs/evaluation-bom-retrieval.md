# BOM 业务准确性与工程知识检索评测

评测依据为工程核查的业务规则和样本原文。本轮新增标签待工程、计划和采购人员复核。评测服务于核查结果与资料适用性的判断，正式版本迁移和业务处置由原流程负责。

| 评测集 | 数据与预期 |
| --- | --- |
| [BOM 业务场景](../examples/evaluation/bom.json) | 7 个场景。包含同料跨版本、同单多行、适用性冲突、跨工厂、上层路径失效、边界日期、采购到货与关闭单。按订单号和订单行比对精确结果，核验待核原因、评审责任、Markdown 中的订单处置，以及是否存在自动迁移或批准动作。 |
| [工程知识检索](../examples/evaluation/retrieval.json) | 15 份合成材料、36 道检索题，其中 28 道有适用证据、8 道缺足够证据。题目按材料段落标注，包含错工厂、错版本、近号、同义改写、分区和无证据情景。另对两条旧引用复验重新审核、移区和撤回。 |
| [候选精度独立评测](../examples/evaluation/retrieval-independent.json) | 1 份既有脱敏验收样例及 6 份合成干扰和对照材料，共 21 题。沿用 5 条既有验收预期，其余 16 题由助手逐段对照原文，在基线检索前锁定标签。使用 8 题定位误召回，另留 13 题复验。 |

保留三类数量口径。版本引用命中只说明订单行指向本次版本。BOM 行候选取决于该行的适用性和订单是否已终止。订单需待业务评审、排除或待核，还要结合状态和执行日期。因此，已证明行适用、订单日期早于拟生效日的对象仍可列为行候选，同时保留待核状态。适用性冲突的订单保留版本引用，行候选为否。

## 本机复跑

默认命令使用标准库。评测在临时目录生成合成 XLSX、SQLite 库和知识库，运行应用导入、规则核查、检索和 Markdown 报告的实际代码。指定模型时使用已通过摘要校验的公开模型文件，Qdrant 索引也建在本次临时目录。

```sh
python3 scripts/evaluate.py
python3 scripts/evaluate.py --report /tmp/bom-evaluation.json
.venv/bin/python scripts/evaluate.py --model ../private/model
python3 scripts/evaluate.py --retrieval-dataset examples/evaluation/retrieval-independent.json
.venv/bin/python scripts/evaluate.py --model ../private/model --retrieval-dataset examples/evaluation/retrieval-independent.json
```

指定 `--report` 时，将路径指向已存在的目录。JSON 逐题记录预期片段、实际返回顺序、引用核验和数据集 SHA-256。模型依赖及准备方式见[本机语义检索](engineering-semantic.md#在独立副本启动)。

`--check` 要求找齐每道题标注的依据，并对证据不足题返回空结果。`--min-candidate-precision 1` 要求所有实际返回的候选均有适用标签。现有 GitHub Actions 通过回归测试按这两个条件检查固定题集的词项模式。设置 `BOM_TEST_MODEL` 后，回归测试也会用已校验的本机 BGE 模型检查相同条件。

## 指标口径

| 指标 | 计算 |
| --- | --- |
| Precision@3 | 对 28 道有证据的题逐题计算「前三项命中适用片段数 ÷ 3」，再取平均。少于三项的空位计入分母。本评测大多只有一条适用片段，标注决定了理论上限 39.3%。 |
| 候选精度 | 全卷标注为适用的实际返回次数 ÷ 全部候选返回次数。包含证据不足题返回的候选，空位不计入分母。 |
| Recall@3 | 对有证据题逐题计算「前三项命中适用片段数 ÷ 该题所有适用片段数」，再取平均。 |
| 引用准确率 | 核对所有返回片段被选入报告后的材料、分区、段落、片段和原文，分母为实际核验的返回片段数。能定位到原文的引用仍可能不适用于本次变更。 |
| 正确拒答率 | 8 道无充分证据题中，返回零个片段的占比。 |
| 过期引用率 | 两条已选用、随后修订或撤回的旧引用中，仍能被检索或重新解析的占比。同时验证旧报告移除原文并提示重新选择、重选旧引用被拒绝。 |

BOM 场景、引用定位和引用失效属于回归断言。Precision@3、Recall@3 和正确拒答率记录当前表现，阈值由业务验收确定。

## 2026-11-19 本机基线

本机修复分支基于 `6fc8e27`，使用合成数据。BOM 场景 7/7 通过。词项模式用 Python 3.14，本机 Qdrant + BGE 用 Python 3.12 和仓库指定的量化模型版本。

| 检索模式 | Precision@3 | Recall@3 | 引用准确率 | 正确拒答 | 旧引用重新出现 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 默认词项 | 32.1% | 84.5% | 57/57 | 3/8 | 0/2 |
| 本机 Qdrant + BGE | 35.7% | 93.5% | 74/74 | 5/8 | 0/2 |

两种模式都在以下无充分证据题返回了候选片段。

- `R29` 查询北厂 V9，返回东厂和西厂的 V1/V2 案例。物料相同，工厂、版本及行号无法匹配。
- `R31` 查询绝缘电阻的合格阈值，返回要求进行检测的材料。材料没有给出阈值。
- `R32` 查询采购承诺取消赔偿与合同号，返回在途去重或其他核查材料。材料没有相应合同条款。

BGE 找回了部分口语改写的对应依据，仍在 `R22` 用其他验证片段替代了在制工单的领料依据，`R23` 和 `R24` 各漏掉一条适用片段。样本覆盖工程知识库的显式问题检索、文本段落及规则报告引用。真实资料、PPT/PPTX 页级检索、自动生成的检索词和独立业务标注仍待单独覆盖。

## 2026-11-19 三处证据不足修复后

显式问题先检查证据，再按原有分数取前三项。可识别的工厂、版本和 BOM 行号须在片段的同一句内同时匹配。要求检测阈值时须有判定数值，明确指定的料号、绝缘或接地电阻以及兆欧单位须出现在对应句。要求取消赔偿金额和合同编号时，片段须同时提供金额和编号。检查使用已审核原文，覆盖常见编码和写法。空白查询沿用按核查上下文自动检索。

用相同数据集、标签和固定模型版本复跑 36 题，两份数据文件的 SHA-256 与基线一致。
